# CS5542 Final Showcase

This repository contains my final combined showcase for **CS 5542**, bringing together **Quiz Challenge I** and **Quiz Challenge II** into one final presentation-ready project.

## Overview

This final showcase highlights two different foundation model projects completed during the semester:

### Quiz Challenge I — Controlled E-Commerce Image Generation
This project used **Stable Diffusion** to generate e-commerce product images from structured product metadata. The work focused on prompt design, including naive prompts, structured prompts, and structured prompts with negative prompting to improve image quality and control.

### Quiz Challenge II — AI Speech Intelligence with Whisper
This project used **OpenAI Whisper Small** to process spoken audio. The system transcribed a short voice recording and then generated a summary, action items, and keywords to make the speech output more useful for productivity tasks such as meeting or project update summarization.

## Purpose of This Final Showcase

The goal of this repository is to present my strongest work from both quiz challenges in one place and demonstrate my technical growth in:
- foundation model usage
- prompt/input design
- output evaluation
- project organization and documentation
